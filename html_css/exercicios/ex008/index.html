Principais formatações

Negrito / Destaque

Forma não semântica: Negrito - com o uso da tag <b>.
Forma semântica: Negrito - com o uso da tag <strong>.

Itálico / Ênfase

Forma não semântica: Itálico - com o uso da tag <i>.
Forma semântica: Itálico - com o uso da tag <em>.
